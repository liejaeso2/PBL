# 📘 Today I Learned

### 1. 오늘 배운 내용

* Supabase 데이터베이스를 React 프로젝트와 연동하는 방법을 배웠다.
* 이메일과 비밀번호를 이용한 회원가입, 로그인, 로그아웃 기능을 구현했다.
* 로그인 여부에 따라 사용 가능한 기능을 구분하고, RLS를 통해 데이터 접근 권한을 설정했다.
* React Router를 사용하여 목록, 상세, 로그인, 회원가입 페이지를 연결했다.

### 2. 핵심 정리 (내 언어로)

* Supabase를 연결하면서 데이터를 데이터베이스에 저장할 수 있게 되었고, 다른 브라우저에서도 같은 명단을 확인할 수 있게 되었다.
* 화면에서 버튼을 제한하는 것뿐만 아니라, RLS 정책을 통해 데이터베이스에서도 비로그인 사용자의 변경을 막아야 한다는 점을 이해했다.
* Supabase 세션을 확인하면 브라우저를 새로고침해도 로그인 상태를 유지할 수 있다.
